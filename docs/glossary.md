# Glossary

| Term | Meaning |
|---|---|
| ARM | Azure Resource Manager, Azure's management/control plane |
| Bicep | Declarative language compiled into ARM JSON |
| CI/CD | Continuous integration and continuous delivery/deployment |
| Environment | Named deployment boundary such as dev/test/prod |
| Federated credential | Entra trust rule accepting an external OIDC identity |
| GitHub Actions | Workflow automation service in GitHub |
| IaC | Infrastructure as Code |
| Idempotent | Repeated application converges on the same desired state |
| LRS | Copies data within one Azure region |
| GRS | Replicates data to a paired secondary region |
| OIDC | OpenID Connect identity federation |
| RBAC | Role-based access control |
| Runner | Machine that executes a GitHub Actions job |
| Scope | Azure boundary where deployment/permission applies |
| Service principal | Entra identity representing an application |
| What-If | Azure preview of expected resource changes |
| Workflow | YAML-defined GitHub automation |
